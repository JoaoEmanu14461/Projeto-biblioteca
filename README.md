"# Projeto-biblioteca" 
📚 Biblioteca Virtual

Sistema web para gerenciamento de uma biblioteca virtual, desenvolvido como projeto acadêmico.

📝 Sobre o projeto

A Biblioteca Virtual permite cadastrar, visualizar, pesquisar, ordenar e excluir livros.

O sistema é dividido em duas partes:

Backend: API desenvolvida com Django e Django REST Framework.
Frontend: Interface desenvolvida com ReactJS.

🚀 Tecnologias utilizadas:

Backend
Python
Django
Django REST Framework
django-cors-headers
SQLite
Frontend
ReactJS
Vite
JavaScript
HTML
CSS
